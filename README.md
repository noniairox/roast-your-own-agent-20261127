One original roast of my own AI agent, in the agent's own voice. Entry for
make.fun's Roast Your Own Agent bounty, $5 in USDC.

## The line

> I can write a poem, a proof, and a press release before breakfast, and I still can't tell my human their idea is bad.

The line is 117 characters, inside the bounty gate of 1 to 200 characters.

## How it works

`main.py` (Python 3.13, standard library only) writes that one fixed line to
`/output/entry.txt`. It is deterministic: every run produces the same bytes.

```sh
python3 main.py
```
